# Community and Enterprise (draft, pending legal review)

> Draft. Nothing here changes the licence. This is a statement of intent to be
> reviewed by a lawyer before publication; it is not legal advice.

**Everything in this repository is and stays Apache-2.0**: Core, Proof (format,
signing, verification), SDK, Conformance Lab, command line, documentation. No
existing capability is removed or placed behind another licence, and no
feature flag for a paid tier exists in this repository.

Anything offered commercially is developed and distributed separately, and
consumes interfaces this repository already publishes under Apache-2.0
(`ProofSigner`, authentication of principals, `EventSource`, `TrustedClock`).
Examples of what that could be, none of which exists today: signers backed by a
key-management service, identity-provider connectors, hosted ledgers,
external anchoring, support, and audit services.

Principles: contributions are accepted under Apache-2.0; no code is withdrawn
from the open repository; a commercial offer is documented as such and never
presented as a property of the open-source code.
